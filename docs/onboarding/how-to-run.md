# How to Run

## Installation

```bash
npm run install
npm run client:install
```

## Environment

Create `.env` file before running the project.

👉 If you don’t have it…  
please **ask your teammate nicely**

> This cannot be provided here for obvious reasons.

---

## Start

```bash
npm run dev
```

## Notes

- make sure `.env` is configured correctly
- installation must be completed before starting
- if something doesn’t work → it’s probably `.env` 😄
